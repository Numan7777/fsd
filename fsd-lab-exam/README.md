# Memory Tricks

| Exp | Remember this core idea |
|---|---|
| 1 | Navbar uses **flex**, projects use **grid** |
| 2 | **setInterval** for the timer, **createElement** for the buttons |
| 3 | **container → row → col-md-4 → card** |
| 4 | **fetch → await → .json() → innerHTML** |
| 5 | **BrowserRouter → Link → Routes → Route** |
| 6 | **useState** stores the list, **useEffect** saves to localStorage |
| 7 | **FormGroup + FormControl + Validators** |
| 8 | **get, post, put, delete** |
| 9 | **$unwind → $group → $sort** |
